# Python 102 - Age Calculator Project

## Project Description
This project is a Python program that collects information about multiple people and calculates their ages based on their birthdates.

The program also identifies the weekday each person was born on and determines the oldest and youngest person.

## Features
- Accepts multiple people's names and birthdates.
- Validates birthdates and handles invalid dates.
- Calculates each person's age.
- Determines the weekday of birth.
- Identifies the oldest and youngest people.
- Displays the total number of people.
- Handles the case when only one person is entered.

## Concepts Used
- Functions
- Lists
- Dictionaries
- Loops (`while` and `for`)
- Conditional Statements (`if`, `elif`)
- Exception Handling (`try` and `except`)
- Date and Time (`datetime`)
- Lambda Functions
- Built-in Functions (`max`, `min`, `len`)

## Technologies
- Python 3
- datetime module
